## デザイン改訂：水面に残る足跡

2026年11月10日。`design/water-footprint-journey` ブランチ。
参考ページの深青・水色・白と明朝体、細い金のアクセントを引き継ぎ、トップの折れ線を水面を歩く足跡に変更。年表にも左右交互の足跡を置き、スクロール位置に応じて足跡が進み、着地のたびに3重の波紋が広がる。逆スクロールでは足跡が戻り、再度進むと波紋を再生する。年表の記録は明るい半透明の面で表示する。
演出は `components/water-footprints.tsx`、今回のスタイルは `app/water-journey.css`。スクロール更新はrequestAnimationFrameに集約し、大きな移動時の波紋発生数を制限する。画面外では波紋を停止し、ResizeObserverでレイアウト変化に追従。右下の停止ボタンとOSの動き低減設定で静止した足跡に切り替わる。装飾はスクリーンリーダーから隠し、日付・記録・詳細ダイアログを引き続き利用できる。

## ワイヤーフレームに沿った軌跡

添付の「軌跡のワイヤーフレーム」を参考に、PCでは情報を左・右・左・右の順に配置し、中央を緩いS字の道でつなぐ。狭い画面（640px以下）は文字の読みやすさを優先し、足跡を左側、情報を右側に並べる。

従来の等間隔に並ぶ30個の足跡を、情報1件につき1個の着地点へ変更。スクロール位置から現在の一歩を算出し、左・右・左・右と片足ずつ進む。3歩目以降は同じ側の前の足跡から移動する。着地のたびにその位置から3重の波紋を広げ、逆スクロールでは足を巻き戻す。大きなスクロール移動でも動く足は1つだけで、波紋の発生位置も最新の着地に限定する。

- `components/journey-timeline.tsx`: 情報カード、足跡、着地の波紋、サイズ変更・動き低減への対応。
- `lib/journey-walk.ts`: スクロール位置から足の位置と着地数を求める計算。
- `app/water-journey.css`: 左右交互のレイアウトと中央の水面の表現。
- `tests/journey-walk.test.mjs`: 一情報一歩、同じ側の足の移動、逆スクロール・高速スクロール・静止状態の検証。

アニメーション停止とOSの動き低減設定では、移動と波紋を止めて全情報の足跡を静止表示する。情報そのものはスクロール位置に関係なく読める。HTMLプレビューは既存の `npm run preview:html` で更新できる。

## 現行デザイン：つながっていく光の線

上記の足跡の演出を、記録同士をつなぐ一本の光の線へ置き換えた。カードの左右交互の配置と水面の色は継承する。スクロール位置に合わせてS字の曲線が伸び、情報ごとの光点に到達すると二重の小さな波紋が広がる。通過した光点と線は残り、逆スクロールでは線が戻る。トップにも同じ光の線を用いる。

- `components/journey-timeline.tsx`: 曲線、光点、到達時の波紋と情報カード。
- `components/hero-light-line.tsx`: トップの光の線。
- `lib/journey-line.ts`: 曲線の生成と、実際の曲線長から先端位置・描画割合を算出。
- `tests/journey-line.test.mjs`: 端の処理、非等速な曲線、逆方向、DOMPointの座標取得を検証。

動きを止める操作とOSの動き低減設定では、すべての光点と線を静止表示する。波紋は画面外で停止する。HTMLプレビューは `npm run preview:html` で再生成する。
